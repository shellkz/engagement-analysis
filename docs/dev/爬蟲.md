# Parse Thread Content
## 情境：


## HTML結構對應資料欄位

### thread
1. title
h1 id="threadTitle" > text
2. catagory
div id="breadcrumb" > 除了開頭(首頁)結尾(自己)之外的span > text
3. created_at
第一篇post的created_at(參考下面post結構)

### post
#### 定位
1. post container
ul id="resList" > post容器
2. post item
post container內部每個li id以"res"開頭

#### resbody 直屬子元素種類（第二個div = div.resbody）
```
div.resbody
├── blockquote.ogp             → thread引用卡片
├── blockquote.twitter-tweet   → Twitter引用（非 iframe，是靜態 blockquote）
├── p                          → 可能是純文字、可能含 a.reslink、可能含 a.thumb
├── br                         → 換行
├── a.thumb                    → 圖片連結（直接子元素）
└── div.reply                  → 被哪幾樓 mention
    └── a.reslink
```

#### 欄位
1. post number
第一個div > span class="resnumber" > text
2. 發文者匿名名稱
第一個div > span class="resname" > text
3. 發文時間
第一個div > span class="resposted" > text
格式:26/05/31(日) 21:00:52 
描述:2025年5月31(金木水火土日本星期)
4. 喜歡數量
第一個div > 最後的button > span class="vcount" > text


5. 內文(純text)
選取：第二個div > 所有direct children的p和br
處理：
- 每個 p → 取 innerText（文字內容），結尾加換行符號
- 每個 br → 加換行符號
- p 內的 a.reslink（>>N）→ 跳過不納入內文（屬於 mention，非正文）
- p 內若只有 a.thumb 且無文字 → 跳過（空白 p，圖片歸 Rule 7）


6. 引用的thread link清單
選取：第二個div > blockquote.ogp > a > href
（限定 blockquote.ogp，排除 blockquote.twitter-tweet）
要區分本站外站
href網域:
https://bbs.animanch.com/
https://animanch.com/
代表本站，其他是外站


7. 引用的圖片清單
選取（兩個來源合併）：
a. 第二個div > direct children的 a.thumb > href
b. 第二個div > direct children的 p > a.thumb > href
（原本只選直接子元素 a，會漏掉被 p 包住的圖片連結）


8. 引用Twitter清單
選取：第二個div > blockquote.twitter-tweet > a[last()] > href
（實際 HTML 是靜態 blockquote，不是 div.twitter > iframe）
取最後一個 a 的 href，即 twitter.com/status/... 格式的原推文 URL


9. mention這樓的postnumber清單
第二個div > div.reply > 所有a.reslink > href
href格式:"#res7"
取出數字"#res{這裡}"

10. mention哪幾樓的postnumber清單
第二個div > 所有direct p > 所有a.reslink > href
href格式:"#res7"
取出數字"#res{這裡}"


## 衝突記錄與修正說明

### 衝突 A：`<p>` 同時命中 Rule 5（內文）和 Rule 10（mention哪幾樓）
- 現象：`<p><a class="reslink" href="#res3">>>3</a></p>` 被 Rule 5 當成內文，同時被 Rule 10 讀為 mention
- 修正：Rule 5 處理時跳過 p 內的 a.reslink 文字；若 p 只包含 a.reslink 則整段略過

### 衝突 B：`<p>` 包住圖片連結，Rule 7 選不到
- 現象：`<p><a class="thumb" href="..."><img></a></p>` — Rule 7 原本只選 direct children的a，選不到 p 裡面的 a.thumb
- 修正：Rule 7 新增來源 b，也從 `p > a.thumb` 選取

### 衝突 C：Twitter embed 格式與 Rule 8 不符
- 現象：實際 HTML 是 `blockquote.twitter-tweet > a`，Rule 8 原本寫 `div class包含"twitter" > iframe > src`，完全選不到
- 修正：Rule 8 改為 `blockquote.twitter-tweet > a[last()] > href`

### 衝突 D：Rule 6 原本用 `所有blockquote`，會把 Twitter URL 也吸入 thread 引用清單
- 現象：`blockquote.twitter-tweet` 也是 blockquote，Twitter 連結被誤歸為 thread link
- 修正：Rule 6 限定為 `blockquote.ogp`，明確排除 `blockquote.twitter-tweet`
