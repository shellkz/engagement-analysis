# 候選 Feature 清單

| Feature                         | 類型   | 定義                                       | 預期意義            |
| ------------------------------- | ---- | ---------------------------------------- | --------------- |
| early_post_mention_sum          | 討論結構 | `sum(len(post.mentions))`                | 早期引用關係總數，衡量互動程度 |
| early_post_mention_mean               | 討論結構 | `reply_edge_count / early_post_count`    | 每篇平均產生多少引用      |
| early_post_mention_ratio          | 討論結構 | `有 mentions 的 post 數 / early_post_count` | 討論是否開始形成回覆鏈     |
| early_post_mention_depth_max           | 討論結構 | 引用樹最大深度                                  | 是否出現長鏈討論        |
| _early_post_mention_depth_mean        | 討論結構 | 所有 post 在引用樹中的平均深度                       | 討論是否持續往下展開      |
